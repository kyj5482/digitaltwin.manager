# 05. 디자인 가이드

프로토타입(`prototype/assets/style.css`)의 토큰이 단일 원천(SSOT)이다.
기존 서비스에 편입할 때는 **`:root` 토큰 값만 기존 브랜드 값으로 교체**하고
컴포넌트 규칙은 유지한다.

## 1. 디자인 토큰

### 1.1 색상 — 면과 잉크
| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` | `#f9f9f7` | `#0d0d0d` | 페이지 배경 |
| `--surface` | `#fcfcfb` | `#1a1a19` | 카드/차트 표면 |
| `--surface-2` | `#f0efec` | `#242422` | 인셋(칸반 트랙, 코드) |
| `--ink-1` | `#0b0b0b` | `#ffffff` | 본문/제목 |
| `--ink-2` | `#52514e` | `#c3c2b7` | 보조 텍스트 |
| `--ink-3` | `#898781` | `#898781` | 뮤트(라벨, 축) |
| `--grid` | `#e1e0d9` | `#2c2c2a` | 헤어라인 |
| `--axis` | `#c3c2b7` | `#383835` | 축/입력 테두리 |

### 1.2 색상 — 액센트·시리즈 (차트용, **검증 완료**)
| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--accent` (시리즈1) | `#2a78d6` | `#3987e5` | 액센트, "진행중", 단일 시리즈 차트 |
| `--series-2` | `#eb6834` | `#d95926` | 두 번째 범주 시리즈 (예비) |
| `--series-3` | `#1baf7a` | `#199e70` | "완료" 시리즈 |
| `--series-neutral` | `#c3c2b7` | `#52514e` | "계획/미착수" 전용 중립 |

검증: `validate_palette.js` 기준 라이트/다크 모두 CVD 분리 ΔE≥9, 정상시력 ΔE≥20 통과.
라이트 모드에서 `--series-3`(aqua)는 표면 대비 2.74:1로 3:1 미만 → **완화 조치 필수**:
세그먼트 값 라벨 + 범례 + 툴팁을 항상 함께 제공한다 (프로토타입 반영됨).

### 1.3 색상 — 상태 (시리즈로 재사용 금지)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--st-good` / `--st-good-text` | `#0ca30c` / `#006300`(라이트 텍스트) | 완료, 리턴 완료 |
| `--st-warning` | `#fab219` | P2, 주의 |
| `--st-serious` | `#ec835a` | P1, 보류 |
| `--st-critical` | `#d03b3b` | P0, 지연, 병목 |

상태 색은 **반드시 아이콘+텍스트와 함께** 사용한다 (⛨ P0, ⏸ 보류, ✓ 완료, ⚠ 지연).
색만으로 의미를 전달하지 않는다.

### 1.4 타이포그래피
- 폰트: `"Pretendard Variable", Pretendard, system-ui, "Noto Sans KR", "Malgun Gothic", sans-serif` — 전 요소 동일(디스플레이/세리프 금지)
- 본문 14px/1.55 · 페이지 제목 21px · 카드 제목 14px bold · 캡션 11–12px
- 큰 숫자(KPI 값)는 기본 비례 숫자, **표 열·축 눈금만 `tabular-nums`**

### 1.5 형태·간격
- 라운드: 카드 10px, 컨트롤 6px · 카드 패딩 18–20px · 그리드 간격 12–16px
- 그림자: 라이트 `0 1px 2px rgba(0,0,0,.05)`, 다크는 그림자 없음(테두리로 구분)

## 2. 컴포넌트 규칙

| 컴포넌트 | 규칙 |
|---|---|
| 배지 | pill형, 아이콘+텍스트. 우선순위(P0~P3)·상태·Goal 상태·채널 4계열 |
| 진행률 미터 | 채움=액센트, 트랙=액센트 18% 틴트(같은 램프의 밝은 단계). 우측에 % 숫자 병기 |
| 테이블 | 헤더 11.5px 뮤트, 행 호버 `--surface-2`, 숫자 열 우측 정렬+tabular |
| 칸반 | 트랙 `--surface-2`, 카드 `--surface`+헤어라인. 체류일 배지, 지연 시 ⚠+critical 색 |
| 스테퍼 | 완료=good 테두리+✓, 현재=액센트 배경 틴트, 예정=점선 테두리 |
| 타임라인 | 좌측 헤어라인+도트. 도트 색: git=액센트, 단계=series-3, 리턴=good. 도트에 2px 표면 링 |
| 모달 | 640px, 스크림 62% + blur 2px(바탕을 어둡게 해 모달 하이라이트), 하단 우측 [취소][주 액션] — 삭제는 모달 안 버튼이 아니라 행 [⋯] 메뉴에서 |
| 폼 | 필수 표시 `*`(critical 색), 힌트 11.5px 뮤트. 라벨 위 배치 |

## 3. 차트 규칙 (dataviz 방법론 적용)

1. **형태 먼저, 색은 마지막.** 단일 값→스탯 타일, 크기 비교→막대, 구성→스택 바.
2. **단일 시리즈 차트는 단일 색**(액센트)이고 범례를 두지 않는다. 값은 막대 끝에
   선택적 직접 라벨 (모든 점에 숫자 금지).
3. **2개 이상 시리즈는 범례 필수** + 세그먼트/끝점 직접 라벨 병행.
4. 막대 두께 ≤24px(프로토타입 20px), **데이터 끝만 4px 라운드**·베이스라인 직각,
   스택 세그먼트 사이 **2px 표면 갭**, 마크 테두리(스트로크) 금지.
5. 축·그리드는 헤어라인 1px 실선, 뮤트 색. **이중 축 금지** — 스케일이 다르면 차트를 나눈다.
6. 텍스트는 항상 잉크 토큰 — 시리즈 색을 글자에 입히지 않는다
   (스택 세그먼트 내부 라벨만 예외: 채움 명도에 따라 흰색/잉크).
7. 모든 막대·세그먼트에 호버 툴팁(제목+값+표본수). 툴팁은 커서 따라다니되 화면 밖 클리핑 방지.
8. 시리즈 색은 엔티티에 고정 — 필터로 시리즈 수가 바뀌어도 남은 시리즈 색을 다시 칠하지 않는다.
9. 새 색이 필요하면 임의 생성 금지 — `--series-2`(orange)를 먼저 쓰고, 그 이상은
   "기타"로 접거나 차트를 분할한다. 팔레트 변경 시 검증 스크립트 재실행.

## 4. 다크 모드

- `prefers-color-scheme` 자동 + 수동 토글(`data-theme`) 병행. 수동 설정이 우선.
- 다크는 라이트의 자동 반전이 아니라 **별도 선정 값** (1.1~1.2 표의 다크 열).
- 기존 서비스에 테마 설정이 있으면 그 설정 값을 상속한다.

## 5. 접근성 체크리스트

- [ ] 상태/우선순위가 색+아이콘+텍스트 3중으로 전달되는가
- [ ] 차트에 범례(≥2 시리즈)와 직접 라벨 또는 툴팁·표 대체가 있는가
- [ ] 시리즈 팔레트 변경 시 검증 스크립트(라이트·다크)를 통과했는가
- [ ] 키보드만으로 칸반 카드 이동·모달 조작이 가능한가 (구현 시)
- [ ] 포커스 링이 `--accent` 2px로 보이는가
